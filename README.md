# Portretto — AI-фотостудия

- `/` — сайт для клиентов (RU/EN): витрина, студия, цены, вопросы
- `/admin` — админка: продажи, генерации, витрина, промокоды, цены
- `/editor` — редактор фото для владельца (вход через админку)
- `/api/health` — быстрая проверка настроек

## Установка на Railway

1. **GitHub.** Загрузите все файлы этой папки в корень репозитория (Add file → Upload files → Commit).
2. **Railway.** New Project → Deploy from GitHub repo → выберите репозиторий.
3. **Хранилище (обязательно).** На схеме проекта нажмите правой кнопкой на сервис → **Attach volume** → Mount path: `/data`. Без этого коды клиентов и заказы пропадут при каждом обновлении.
4. **Переменные** (сервис → Variables):

| Переменная | Что это |
|---|---|
| `FAL_KEY` | Ключ fal.ai (обязательно) |
| `ADMIN_PASSWORD` | Пароль от админки (обязательно) |
| `STRIPE_SECRET_KEY` | Секретный ключ Stripe `sk_live_…` или `sk_test_…` |
| `STRIPE_WEBHOOK_SECRET` | Секрет вебхука Stripe `whsec_…` |
| `STUDIO_NAME` | Название (по умолчанию Portretto) |
| `CONTACT_EMAIL` | Почта поддержки в подвале сайта |
| `PUBLIC_URL` | Адрес сайта, если подключили свой домен |
| `FAL_MODEL` | Модель, по умолчанию `fal-ai/nano-banana-pro/edit` |
| `FAL_RESOLUTION` | `1K`, `2K` или `4K`, по умолчанию `2K` |
| `FAL_COST_PER_IMAGE` | Цена одного портрета в fal.ai, для подсчёта расходов в админке |
| `TRIAL` | `off` — выключить бесплатную пробу для новых клиентов (по умолчанию включена) |
| `TRIAL_COUNT` | Сколько портретов в бесплатной пробе, по умолчанию 3 |
| `TRIAL_DAILY_LIMIT` | Сколько бесплатных проб в сутки на весь сайт, по умолчанию 100 |
| `TRIAL_WATERMARK` | Текст водяного знака на пробных портретах, по умолчанию `Portretto.app` |

5. **Адрес.** Settings → Networking → Generate Domain.

## Stripe

1. dashboard.stripe.com → Developers → **API keys** → скопируйте Secret key в `STRIPE_SECRET_KEY`.
2. Developers → **Webhooks** → Add endpoint:
   - URL: `https://ВАШ-АДРЕС/api/stripe/webhook`
   - Событие: `checkout.session.completed`
   - После создания скопируйте Signing secret (`whsec_…`) в `STRIPE_WEBHOOK_SECRET`.
3. Для проверки сначала используйте тестовые ключи (`sk_test_…`) и карту `4242 4242 4242 4242`, любой срок и CVC. Потом замените на боевые.

## Как это работает

- Клиент покупает пакет → Stripe → возвращается на сайт с личным кодом `PT-XXXX-XXXX-XXXX` и балансом.
- Один кредит = один портрет. Если генерация не удалась, кредиты возвращаются автоматически.
- По коду клиент видит баланс и все свои портреты на любом устройстве.
- В админке можно создавать промокоды (бесплатные кредиты), менять цены пакетов и выбирать лучшие работы для витрины на главной.

## Бесплатная проба

- При первом заходе новому посетителю показывается предложение попробовать бесплатно.
- Проба — один заказ из 3 портретов. Клиент получает личный код без кредитов; после покупки пакета кредиты добавляются к этому же коду, пробные портреты остаются в «Моих заказах».
- На пробные портреты сервер накладывает водяной знак и уменьшает их до 1080 px; оригиналы клиенту не отдаются.
- Защита от злоупотреблений: одна проба с одного IP-адреса раз в 30 дней и общий лимит в сутки (`TRIAL_DAILY_LIMIT`). Если проба не удалась, она возвращается.
- Себестоимость одной пробы ≈ 3 портрета по цене модели по умолчанию в fal.ai (плюс перенос лица, если включён).

## Поиск: Google и ИИ-поисковики

- Главная в трёх языковых версиях с отдельными адресами: `/` — испанский (основной), `/en` — английский, `/ru` — русский. Старые адреса `/?lang=en` и `/?lang=ru` перенаправляются (301).
- Каждая версия отдаётся сервером уже переведённой: текст, образы, цены и вопросы есть в HTML без JavaScript. Это важно для ИИ-ботов (ChatGPT, Claude, Perplexity), которые не запускают скрипты.
- Между версиями стоят `hreflang`, у каждой свой `canonical`; разметка Organization, WebSite, Service с ценами пакетов и FAQPage.
- Посетителя при первом заходе переводит на версию на языке его телефона; поисковых ботов — нет.
- `robots.txt` явно разрешает Google, Bing, GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Applebot и др.; закрыты админка, API и пробные портреты.
- `/llms.txt` и `/llms-full.txt` — описание сервиса, цен и вопросов для ИИ-поисковиков.
- Заголовки и описания главной для каждого языка меняются в `/seo`.
